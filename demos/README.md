# Сценарии демо-чата

Демо на сайте — имитация Telegram. Бот ничего не вычисляет и никуда не подключается:
он показывает шаги, записанные в JSON-файле. Код (`js/demo.js`) при добавлении
нового проекта менять не нужно.

## Как добавить проект

1. Скопируйте `consultant.json` под новым именем, например `salon.json`, и поменяйте тексты.
2. Добавьте строку в `index.json`:

   ```json
   { "id": "salon", "tab": "💇 Салон", "file": "salon.json" }
   ```

   `id` — латиницей; его же можно указать у кнопки на странице: `data-demo="salon"`.
3. Откройте сайт через локальный сервер (`python -m http.server` в папке сайта)
   и пройдите сценарий. Если кнопка ведёт в несуществующий шаг, в консоли браузера
   (F12 → Console) появится предупреждение.

## Устройство файла

```json
{
  "bot":   { "name": "Название бота", "avatar": "🤖", "status": "бот" },
  "about": { "title": "...", "text": "...", "try": ["что попробовать", "..."] },
  "inactive": "Подсказка для кнопок, которые в демо не работают",
  "start": "begin",
  "vars": { "qty": "0" },
  "keyboards":   { "main": [[кнопка, кнопка], [кнопка]] },
  "suggestions": { "questions": [кнопка, кнопка] },
  "steps": { "begin": { ... }, "start": { ... } }
}
```

- `about` — текст слева от окна чата.
- `start` — с какого шага начинается демо.
- `keyboards` и `suggestions` — общие наборы кнопок, чтобы не повторять их в каждом шаге.

### Шаг

```json
"ask_phone": {
  "messages": [
    { "text": "📞 Ваш номер телефона?" },
    { "from": "service", "text": "Пояснение для посетителя сайта" }
  ],
  "keyboard": "main",
  "suggest": [ { "text": "+7 900 123-45-67", "next": "ask_address" } ],
  "placeholder": "Ваш телефон",
  "edit": true,
  "toast": "Добавлено в корзину",
  "set": { "qty": "2" },
  "auto": "next_step",
  "autoDelay": 1500
}
```

| Поле | Что делает |
|---|---|
| `messages` | Сообщения по очереди. `from`: `bot` (по умолчанию), `user` или `service` — серая плашка по центру с пояснением. |
| `buttons` (внутри сообщения) | Inline-кнопки под сообщением: список рядов, в ряду — кнопки. |
| `keyboard` | Кнопки внизу экрана: ряды кнопок или имя набора из `keyboards`. `null` — убрать. Не указано — остаются прежние. |
| `suggest` | Подсказки «что напечатать»: клиент как будто пишет текст сам. Так же, как `keyboard`: список, имя набора или `null`. |
| `placeholder` | Серый текст в поле ввода. |
| `edit` | Если шаг открыт inline-кнопкой, первое сообщение заменяет то, под которым нажали кнопку (бот правит сообщение, а не присылает новое). |
| `toast` | Всплывающая подсказка, как ответ бота на нажатие кнопки. |
| `set` | Запомнить значения переменных. |
| `auto` | Перейти к следующему шагу самому, без нажатия — через `autoDelay` миллисекунд. |

### Кнопка

```json
{ "text": "📱 Поделиться контактом", "say": "📱 Контакт: +7 900 123-45-67",
  "next": "ask_address", "set": { "phone": "+7 900 123-45-67" }, "toast": "..." }
```

- `next` — шаг, который откроется. Нет `next` — кнопка показывает `toast` кнопки
  или общий `inactive`.
- `say` — что появится в чате от клиента (для кнопок внизу и подсказок).
  Не указано — текст кнопки. Inline-кнопки текст в чат не отправляют, как в Telegram.
- `set` — запомнить значения при нажатии.

### Переменные

В любом тексте, в `next` и в `set` можно подставить переменную: `{qty}`, `{total}`.
Так в пекарне одна кнопка «🛒 Корзина» ведёт в `cart_{qty}` — корзину с нужным
количеством товара, а в сводке заказа подставляются адрес и итог.

### Разметка текста

`**жирный**`, `` `код` ``, перенос строки — `\n`.
